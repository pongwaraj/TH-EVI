# ชุดข้อมูล Heat Map: ชุมแพ ขอนแก่น

พิกัดวิเคราะห์: `16.552857, 102.081701` (H33J+2MJ), อำเภอชุมแพ จังหวัดขอนแก่น
ตรวจสอบแหล่งข้อมูลและจัดชุดข้อมูล: 12 ตุลาคม 2569

## DLT

ข้อมูลจดทะเบียนสะสมล่าสุดที่ใช้ในชุดนี้อ้างอิง ณ 31 สิงหาคม 2569: รถกลุ่ม รย.1-3 จำนวน 466,120 คัน, BEV 7,483 คัน และ PHEV 1,010 คัน หรือ BEV+PHEV 1.8221% ของกลุ่มรถดังกล่าวในระดับจังหวัด ตัวเลขนี้เป็นบริบทตลาดระดับจังหวัด ไม่ใช่จำนวนรถ EV ของอำเภอชุมแพหรือจำนวนลูกค้าที่จะเข้ามาชาร์จที่จุดวิเคราะห์

ประชากรตามทะเบียนของอำเภอชุมแพใน district node ปัจจุบันคือ 84,332 คน (DOPA 2568) ใช้เป็นเพียงบริบทพื้นที่ ไม่ใช่จำนวนผู้เดินทางหรือฐานลูกค้า EV

## POI รอบพิกัด

เพิ่มจุดที่มีชื่อสถานที่และพิกัดแผนที่รองรับ ได้แก่ โรงพยาบาลชุมแพ (~2.1 กม.), สถานีขนส่งผู้โดยสารอำเภอชุมแพ (~2.3 กม.), เทศบาลเมืองชุมแพ (~3.3 กม.) และ Lotus's Chum Phae (~4.4 กม.) ระยะทางเป็นเส้นตรงจากพิกัดวิเคราะห์ ไม่ใช่ระยะขับรถ และ POI ไม่ได้เท่ากับจำนวนผู้ใช้บริการ/ดีมานด์ชาร์จ

## Competitors

- PEA VOLTA Chum Phae: ประมาณ 0.49 กม. จากพิกัด โดยระบุตำแหน่งจาก Plus Code `H32P+88R`. ยืนยันการมีรายการสถานีได้ แต่ข้อมูลหัวชาร์จ/กำลังไฟจากไดเรกทอรีขัดแย้งกัน จึงไม่ระบุ kW เป็นค่าที่ยืนยันแล้ว; โมเดลปัจจุบัน fallback เป็น 2 หัว/120 kW เมื่อไม่มี metadata และระเบียนนี้ถูกลดตัวคูณคู่แข่งเพราะสถานะข้อมูลขัดแย้ง
- ReverSharger (Sharge) Chai So: ประมาณ 3.38 กม. จากพิกัด โดยระบุตำแหน่งจาก Plus Code `G4M4+79F`. ONE EV Station แสดง CCS2 120 kW 2 หัว และ Type 2 22 kW 2 หัว; สถานะว่างเป็นข้อมูลจาก user check-in ไม่ใช่ประวัติการใช้งานที่ตรวจสอบแล้ว

ระยะคู่แข่งเป็นระยะเส้นตรง และทั้งสองรายการต้องตรวจสถานะ/จำนวนหัว/กำลังจริงในแอปของผู้ให้บริการก่อนใช้หักดีมานด์เชิงพาณิชย์ ห้ามแปลงจำนวนหัวชาร์จเป็นจำนวนลูกค้าหรือ utilization โดยตรง
