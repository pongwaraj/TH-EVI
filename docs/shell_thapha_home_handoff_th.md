# ทำงานต่อโครงการ Shell ท่าผา

ข้อมูลตรวจทาน 27 ตุลาคม 2569 จุดวิเคราะห์ 17.650561, 99.249117 จังหวัดลำปาง อำเภอเถิน

## รับโค้ดและเปิดแอพ

ในโฟลเดอร์ checkout ของเครื่องที่บ้าน ตรวจ `git status` ก่อน หากมีงานค้างให้เก็บงานนั้นก่อนดึงข้อมูล ไม่ใช้คำสั่งล้างงานค้าง

```powershell
git fetch origin
git pull --ff-only origin master
python -m pip install -r requirements.txt
python -m uvicorn th_evi.api:app --host 127.0.0.1 --port 8000
```

เปิด `http://127.0.0.1:8000/planning` แล้วค้น `เชลล์ท่าผา` หรือวาง `17.650561, 99.249117` หากพอร์ต 8000 มีแอพอื่นอยู่ ให้ใช้พอร์ตว่างแทน

ข้อมูลอ้างอิงที่จำเป็นสำหรับ Shell มีใน repo ใช้งานแบบ CSV fallback ได้โดยไม่ต้องนำไฟล์ SQLite ของเครื่องสำนักงานไปด้วย หากต้องเชื่อม Neon ให้ใช้ค่า environment ที่ได้รับอนุญาตของเครื่องนั้นแยกต่างหาก ไม่เก็บ credentials ลง Git

## ข้อมูลล่าสุดที่รวมในชุดนี้

- POI ของ Shell โรงพยาบาลเถิน และจุดขึ้นรถเถิน พร้อมหลักฐานและพิกัด
- DLT รถยนต์นั่ง รย.1 กันยายน 2569 ลำปาง BEV 1,725 คัน จากรถยนต์นั่ง 100,950 คัน
- AADT กรมทางหลวงปี 2568 ดอนไชย–สบปราบ 13,337 คัน/วัน ใช้เป็นบริบทถนนใกล้เคียง ไม่ใช่ยอดรถเข้าปั๊ม
- DOPA ปี 2568 เถิน 55,218 คน รวมเขตเทศบาลที่แยกอยู่ในไฟล์ต้นทางแล้ว
- สเปกคู่แข่งตามข้อมูลผู้ประสานงาน: PT เถิน 124 kW, PT เถิน 3 ขนาด 150 kW, Spark เถิน–นภา 240 kW จำนวน 2 ตู้
- PT เถินยังไม่มีพิกัดที่ยืนยัน จึงไม่สร้างหมุดหรือระยะสมมติ กำลังไฟที่แจ้งใหม่ไม่ใช่การตรวจแอปผู้ให้บริการอย่างอิสระ

## รายงานและการคำนวณ

รายงานฉบับล่าสุดอยู่ที่ `outputs/shell_thapha_owner_area_analysis/Area_Analysis_Shell_Tha_Pha_DC180kW_20261027.docx` และบันทึกสูตรกับข้อมูลรายปีไว้ใน `calculation_audit.json` ในโฟลเดอร์เดียวกัน

ข้อมูลนำเข้าสำหรับสร้างซ้ำอยู่ที่ `data/site_analysis/shell_thapha_thoen_20261027.json` ไม่พึ่ง JSON ชั่วคราวของเครื่องสำนักงาน

```powershell
python artifacts/build_shell_thapha_owner_area_analysis.py
```

ไฟล์โลโก้และแผนที่จริงที่รายงานใช้อยู่ใน repo แล้ว ไม่ต้องอ้างไฟล์ Desktop ของเครื่องสำนักงาน สคริปต์ต้องใช้ `python-docx` ใน requirements และควรมีฟอนต์ TH Sarabun New บนเครื่องที่เปิดเอกสาร

หากต้องการจับภาพแผนที่ใหม่ ให้เปิดเซิร์ฟเวอร์ก่อน ใช้ Node.js ที่มี Playwright แล้วรัน `node artifacts/capture_shell_thapha_report_map.cjs` กำหนด `PLAYWRIGHT_MODULE` หรือ `CHROMIUM_EXECUTABLE_PATH` ได้หากตำแหน่งแพ็กเกจหรือ Chrome ต่างจากค่าปกติ หากต้อง render ผ่าน Microsoft Word สคริปต์ `artifacts/render_the_local_word.vbs` ต้องใช้ Windows ที่ติดตั้ง Word

## จุดที่ต้องระวังในการวิเคราะห์ต่อ

- กำลังสถานีของโครงการ 180 kW จำนวน 1 ตู้ 2 ช่องจอด เงินลงทุน 2,300,500 บาท
- ค่าเริ่มต้น 2 คัน/วันมาจากผลคัดกรองเดิมที่นำมาใช้เป็นสมมติฐานวางแผน ยังไม่ใช่ยอดลูกค้าที่สำรวจจากสถานีนี้ และไม่มีข้อมูลสถานีอ้างอิงที่สอบเทียบสำหรับลำปาง
- รายงานคงยอดรถและต้นทุนตลอด 10 ปี โดยไม่ได้ใส่การเติบโตอัตโนมัติ และคงผลการเงินตามสมมติฐานดังกล่าว
- คะแนน Heat ใกล้ปั๊มต่ำกว่าเกณฑ์แสดงสี 30% ในหน้า Planning แม้มีข้อมูลกริดอยู่ จึงอาจไม่เห็นสีที่จุดนี้ ไม่ได้เปลี่ยนเกณฑ์เพื่อบังคับให้พื้นที่ร้อน
- ชั้นน้ำออนไลน์อาจไม่พร้อมใช้งาน และระยะคู่แข่งเป็นระยะเส้นตรง ยังไม่ใช่เส้นทางขับ/จุดกลับรถ
- การ push ครั้งนี้ไม่สั่ง deploy production และไม่แก้ข้อมูลใน production Neon DB
