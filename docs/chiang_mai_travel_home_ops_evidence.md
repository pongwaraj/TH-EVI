# หลักฐานการเดินทาง ที่อยู่อาศัย และการชาร์จ: pilot เชียงใหม่

ตรวจข้อมูล 17 ตุลาคม 2569 ชุดนี้เป็นหลักฐานประกอบตัวจำลองเที่ยวรถ/SOC และใช้ได้กับโครงสร้าง profile ร่วมของทุกจังหวัด แต่ยังไม่ใช่ forecast สถานีหรือการปรับ Heat Map

## 1. ระยะทางบนถนน

- [ต้นทาง 5 โครงการ](../data/chiang_mai_travel_origins.csv): บ้านจัดสรร 4 แห่ง และคอนโด 1 แห่ง เลือกเป็นตัวอย่างจากแผนที่ที่ผู้พัฒนาโครงการเผยแพร่ พิกัดยังไม่ใช่ทางเข้าที่ตรวจหน้างาน
- [เส้นทาง 29 คู่](../data/chiang_mai_travel_routes.json): บ้าน/คอนโดไปประตูท่าแพเป็นตัวแทนใจกลางเมือง รวมถึง มช. MAYA เซ็นทรัลเฟสติวัล และกลุ่ม รพ.มหาราช; มีเส้นทางจากใจกลางเมืองไปยังจุดหมายหลักด้วย
- คำนวณระยะไปและระยะกลับแยกกันด้วย OSRM บนถนน OpenStreetMap; ระยะไปกลับของคู่ที่รองรับอยู่ที่ประมาณ 6.5–36.9 กม. ระยะเกาะถนนสูงสุดของจุดตัวอย่างราว 26 เมตร ไม่มีการแปลงระยะเส้นตรงเป็นระยะถนน
- ประตูท่าแพเป็นจุดแทนใจกลางเมือง ไม่ใช่ปลายทางจริงของทุกเที่ยว จุด POI มาจาก seed และยังไม่ได้ยืนยันประตูเข้า จำนวนเที่ยว/วัน ความถี่การเดินทาง สัดส่วนที่เลือกแต่ละปลายทาง และสัดส่วนเจ้าของ EV ในแต่ละโครงการยังไม่มี จึงไม่เฉลี่ย 29 เส้นทางเป็น daily km จังหวัด
- สร้างซ้ำด้วย `python scripts/build_travel_route_evidence.py --matrix tmp/chiang_mai_route_matrix.json` เมื่อมี matrix ที่เก็บไว้; หากเรียก routing ใหม่ ผลอาจเปลี่ยนตามเครือข่ายถนน

## 2. บ้าน คอนโด และการชาร์จที่บ้าน

- [สำนักงานสถิติจังหวัดเชียงใหม่ รายงานสถิติจังหวัด พ.ศ. 2567 ตาราง 1.10 หน้า 19](https://chiangmai.nso.go.th/images/2025/SPB2567-50-%2008-11-67_compressed.pdf): ครัวเรือนปี 2566 อยู่บ้านเดี่ยว 85.1%, ห้องแถว/อาคารพาณิชย์ 10.3%, ทาวน์เฮาส์/บ้านแฝด 0.1%, ห้องชุด/แฟลต 4.0%, ที่พักชั่วคราว 0.5% ข้อมูลเป็น **ครัวเรือนทั้งจังหวัด ไม่ใช่สัดส่วนที่อยู่ของเจ้าของ EV** และห้องชุด/แฟลตกว้างกว่าคอนโดตามกฎหมาย
- [กกพ. บทความปี 2567](https://www.erc.or.th/th/energy-articles/3094) อ้างข้อมูลเบื้องต้นกระทรวงพลังงานว่าผู้ใช้ EV ไทยนิยมชาร์จที่บ้านมากถึง 80% นี่เป็นพฤติกรรม/สถานที่ชาร์จระดับประเทศ **ไม่ใช่** อัตราติดตั้ง wallbox ของเจ้าของ EV ในบ้านเดี่ยวเชียงใหม่
- [PwC Strategy& ASEAN-6 eReadiness 2025](https://www.pwc.com/id/en/publications/automotive/pwcid-ereadiness-2025-asean-report.pdf) สำรวจเจ้าของ EV ในภูมิภาคเรื่องสถานที่ชาร์จหลักและที่จอดส่วนตัวที่บ้าน แต่ไม่แจกแจงอัตรามี AC Charger แบบมีเงื่อนไขตามประเภทบ้านของเชียงใหม่ จึงใช้ตรวจทิศทางพฤติกรรมเท่านั้น
- ข้อเสนอว่า “บ้านส่วนมากมี AC / คอนโดส่วนมากไม่มี” ยังไม่มี conditional rate ที่ยืนยันได้ ชุดข้อมูล [housing evidence](../data/chiang_mai_home_charging_evidence.json) จึงเก็บ `null` ทั้งสองอัตรา; คอนโดบางแห่งมีที่ชาร์จส่วนกลาง การตั้ง private wallbox เป็นศูนย์อาจใช้เป็น scenario แต่ห้ามอ้างว่าเป็นค่าที่สำรวจได้
- ไม่เอา 85.1% × 80% ไปเป็นสัดส่วน EV ที่มี home AC เพราะฐานประชากร ตัวตั้ง และความหมายต่างกัน

## 3. พฤติกรรมจากระบบปฏิบัติการสถานี

- อ่านข้อมูลแบบ aggregate จากแอป `D:\Work\EV Station Operation Team` ช่วง 1 ก.ค.–30 ก.ย. 2569 ที่ Meta Mall เชียงใหม่; ไฟล์ [ผลสรุป](../data/chiang_mai_operations_behavior_2026q3.json) ไม่มีตัวระบุลูกค้าหรือรายการ
- คำสั่งซื้อสถานะ Normal 3,421 รายการ, 86,755.14 kWh, เฉลี่ย 25.36 kWh/รายการ; เมื่อกรอง Normal ที่ชาร์จอย่างน้อย 5 นาทีและ 1 kWh เหลือ 3,147 รายการ, 86,285.97 kWh, เฉลี่ย **27.42 kWh/รายการ**
- ค่า 35 kWh/คันที่ใช้ในรายงานเดิมเป็นสมมติฐานที่สูงกว่าค่าเฉลี่ยรายการที่สังเกตในสถานีนี้ แต่รายการหนึ่งอาจไม่ใช่รถหนึ่งคันหรือการมาใช้บริการหนึ่งครั้ง จึงยังไม่แทนค่า 35 kWh ของทั้งจังหวัดโดยอัตโนมัติ
- ข้อมูล schema มีช่อง SOC เริ่มและจบ แต่ API แบบสรุปที่เข้าถึงได้ยังไม่ส่งการกระจาย SOC จึงไม่มีหลักฐาน SOC เริ่มชาร์จจริงสำหรับ pilot นี้ ความครบของรายการนำเข้าและ uptime ยังไม่ได้พิสูจน์
- ตัวเลข Meta Mall เป็นลูกค้าที่เลือกสถานีอยู่แล้ว ไม่ใช่ตัวอย่างสุ่มของผู้ถือครอง EV เชียงใหม่ ไม่สามารถใช้เป็นอัตราการเลือกสถานีใหม่โดยตรง

### ทดสอบเดือนที่ไม่ใช้หาค่าเฉลี่ย

[ผลทดสอบ temporal holdout](../data/chiang_mai_operations_holdout_2026q3.json) ใช้ ก.ค.–ส.ค. 2569 เป็นช่วงหาค่าเฉลี่ยรายการที่ผ่านเกณฑ์ 1,941 รายการ, 54,553.11 kWh = 28.11 kWh/รายการ แล้วทดสอบกับ ก.ย. 2569 ที่มี 1,206 รายการ, 31,732.86 kWh = 26.31 kWh/รายการ ค่าจากสองเดือนแรกพยากรณ์ **พลังงานรวมเมื่อทราบจำนวนรายการเดือนกันยายนแล้ว** สูงกว่าจริง 6.8%; ถ้าทดลองสมมติ 35 kWh **ต่อรายการ** จะสูงกว่าจริง 33.0% แต่ตัวเลข 35 kWh/คันในเอกสารเดิมเป็นคนละหน่วย จึงไม่ใช้การเทียบนี้ตัดสินว่าเอกสารเดิมผิด

นี่เป็นเพียงการตรวจ *ขนาดการชาร์จต่อรายการ* ของ Meta Mall เดือนเดียว ไม่ได้ทำนายจำนวนรายการล่วงหน้า ไม่ได้ตรวจสถานีอื่น และไม่ใช่ผลวัดความแม่นยำของ Heat Map

## 4. ชั้นทดลอง normalize และ sensitivity

- `GET /api/charging-demand/route-evidence?province=Chiang%20Mai` ให้รหัสต้นทาง/ปลายทางและระยะถนนที่ใช้ได้
- `POST /api/charging-demand/evidence-preview` รับรหัสคู่เส้นทาง พร้อมสมมติฐานที่ต้องระบุเอง ได้แก่ จำนวนครั้งไปกลับต่อสัปดาห์, kWh/km, สัดส่วนที่เข้าถึงการชาร์จบ้าน, สัดส่วนพลังงานที่เติมบ้านเมื่อเข้าถึงได้, สัดส่วน AC อื่น, สัดส่วน DC จากพลังงานที่เหลือ และประสิทธิภาพฝั่งรถ
- ผลคือบัญชีพลังงานของ **รถตัวอย่างหนึ่งคันต่อสัปดาห์** แยก home/AC อื่น/DC/ยังไม่จัดสรร และแสดงกรณี home access ±20 จุดเปอร์เซ็นต์จากค่าที่ใส่ โดยไม่เกิน 0–100%
- จำนวน `meta_mall_meaningful_order_equivalents` ใช้ค่าเฉลี่ยช่วงฝึก 28.11 kWh/รายการ เป็นหน่วยเทียบพลังงานเท่านั้น ไม่ใช่จำนวนคันหรือคำทำนายยอดขายสถานี ผู้ใช้ต้องตรวจ SOC feasibility แยกใน `/api/charging-demand/travel-preview`
- คำตอบ API ระบุ `assumption_sensitivity_not_calibrated`, `forecast_enabled=false`, `heatmap_changed=false` และไม่ยืมหลักฐานเชียงใหม่ให้จังหวัดอื่น

ตัวอย่าง request สำหรับ **ทดสอบสมมติฐานเท่านั้น** ค่า 0.18 kWh/km, 5 ครั้ง/สัปดาห์ และสัดส่วนทั้งหมดในตัวอย่างนี้ไม่ได้อ้างว่าเป็นค่าที่สำรวจจากเชียงใหม่:

```json
{
  "province": "Chiang Mai",
  "origin_id": "ornsirin_11",
  "destination_id": "thapae_gate",
  "outings_per_week": 5,
  "battery_kwh_per_km": 0.18,
  "home_access_share": 0.6,
  "home_energy_share_if_access": 0.8,
  "other_ac_share_of_remaining": 0.1,
  "dc_share_of_remaining": 0.7,
  "dc_vehicle_efficiency": 0.92
}
```

## สถานะนำไปใช้

`GET /api/charging-demand/basis?province=Chiang%20Mai` แสดงหลักฐานเส้นทาง ที่อยู่อาศัย พฤติกรรมสถานี และผล temporal holdout ใน `pilot_evidence` พร้อมสถานะ `pilot_evidence_not_calibrated` และ `forecast_enabled=false`; จังหวัดอื่นไม่ยืมหลักฐานเชียงใหม่ `spatial_energy_enabled=false` จึงยังไม่เปลี่ยน Heat Map

ขั้นที่ยังต้องมีเพื่อคำนวณ demand รายพื้นที่: สัดส่วนบ้านของเจ้าของ BEV, อัตราเข้าถึง home/work AC ตามประเภทที่อยู่อาศัย, ตัวอย่างความถี่เที่ยวและปลายทางจริง, รถ/แบตเตอรี่/efficiency และ SOC, แล้วจึง calibration/holdout กับ log สถานีหลายแห่ง พร้อม station choice และความจุหัวชาร์จ หากยังไม่มีข้อมูลเหล่านี้ ผลจำลองเป็น scenario ไม่ใช่ตัวเลขคาดการณ์ที่ยืนยันแล้ว
