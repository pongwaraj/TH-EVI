# ข้อมูล Heat Map: Shell ท่าผา อำเภอเถิน ลำปาง

ตรวจทาน 27 ตุลาคม 2569 | จุดวิเคราะห์ 17.650561, 99.249117

## ตำแหน่งและลักษณะพื้นที่

- [Shell locator](https://find.shell.com/th/fuel/12849483-do-subcharean-oil-thoen-lpg) ยืนยันสถานี DO SUBCHAREAN OIL THOEN LPG เลขที่ 197 หมู่ 5 ตำบลแม่ปะ อำเภอเถิน ลำปาง 52160 พิกัด 17.650371, 99.248910 ห่างจุดวิเคราะห์ประมาณ 30 เมตร ส่วนเติมน้ำมันเปิด 24 ชั่วโมง
- เลขที่ 50/1 หมู่ 7 เป็น [Shell CO WANGTHIP THOEN LPG](https://find.shell.com/th/fuel/10042056-co-wangthip-thoen-lpg) ตำบลล้อมแรด ซึ่งเป็นคนละสถานี ไม่รวมที่อยู่หรือสิ่งอำนวยความสะดวกข้ามสาขา
- เป็นจุดพักริมทาง ไม่ใช่ Community Mall หรือแหล่งท่องเที่ยวขนาดใหญ่ ใช้หมวด highway_service_area ซึ่งมีน้ำหนัก 8 และรัศมี 1.2 กม. เท่าปั๊มทั่วไป แต่จัดประเภททำเลเป็น highway เพื่อใช้บริบทถนน ไม่เพิ่มตัวคูณเฉพาะโครงการ และไม่เปลี่ยนหมวดปั๊มอื่นตามไปด้วย
- [Maple House ShellTarpa](https://restaurantguru.com/Maple-House-ShellTarpa-Lom-Raet) มีรายการร้านกาแฟที่เลขที่ 197 แม่ปะ ใช้เป็นบริบทของสถานีเดียวกัน ไม่เพิ่ม POI ซ้ำ ร้านกาแฟไม่ได้ยืนยันว่าเปิด 24 ชั่วโมง
- เว็บไซต์ Shell ไม่แสดงข้อมูล EV charging จึงยังสรุปไม่ได้ว่าไม่มีเครื่องชาร์จเดิม

| 1 / 1102 ดอนไชย–สบปราบ | 617+097 | 13,337 | ตัวแทนบริบทแนวถนนใกล้ Shell ไม่ใช่ตัวนับหน้าปั๊ม |
| 1 / 1101 แม่เชียงรายบน–ดอนไชย | 589+255 | 12,868 | บริบทคนละช่วงถนน ไม่บวกกับแถวแรก |

| 1124 / 100 ท่าผา–ปางกุ่ม | 8+434 | 863 | ถนนรอง ไม่บวกเข้าทางหลวง 1 |

กำหนด override เฉพาะกรอบ 17.645–17.657, 99.244–99.254 ให้ใช้ 13,337 แทน fallback 8,000 และไม่ยืมยอดเกาะคา/ตัวเมือง 56,026 หรือ 59,929 มาใช้ที่เถิน กรอบนี้เป็นวิธีประมาณแนวถนนของระบบเดิม ไม่ใช่ผล map-matching หรือข้อมูลการเดินทางถึงทางเข้า

AADT รวมรถหลายชนิดทั้งรถโดยสารและรถบรรทุก ไม่ใช่จำนวนลูกค้าชาร์จ ไม่ทราบทิศทางแยกขาเข้า/ขาออกหรือสัดส่วนที่เลี้ยวเข้าปั๊ม และไม่ควรคูณสัดส่วน EV จดทะเบียนลำปางแล้วถือเป็นจำนวนรถ EV ผ่านจริง เพราะเส้นนี้มีรถข้ามจังหวัด

## รถจดทะเบียน DLT

อ้างอิงไฟล์นำเข้า `fuel30Sep26_W.xlsx` ณ 30 กันยายน 2569 ที่มีอยู่ในโครงการ (`data/evhub_dlt_fleet_2569_09.csv` และ `data/dlt_ev_province_20260930.csv`) จาก [DLT](https://web.dlt.go.th/statistics/load_file_select_new_car.php?t=3&data_file=1302) ไม่ใช่ยอดสำรวจผู้ใช้ปั๊ม และไม่ได้อ้างว่าดาวน์โหลดไฟล์เดือนใหม่กว่าแล้ว

| ขอบเขตรถลำปาง | รถทั้งหมด | BEV | PHEV |
|---|---:|---:|---:|
| รย.1 รถยนต์นั่งส่วนบุคคล | 100,950 | 1,725 | 168 |
| รย.1–3 รวมตามตาราง EV จังหวัด | 190,737 | 1,731 | 168 |

โมเดลใช้ฐาน BEV รย.1 จำนวน 1,725 คัน / 100,950 คัน หรือ 1.709% ในปี 2569 แทนยอดสังเคราะห์จากเส้นเติบโตเดิม ไม่บวกรถจักรยานยนต์หรือ PHEV เข้าเป็น BEV ที่ใช้ DC ทั้งหมด ปีหลัง 2569 ยังเป็นการคาดการณ์ตามสมมติฐานการขายและการปลดระวางของโมเดลเดิม ไม่ใช่ยอด DLT ที่สังเกตแล้ว

## การใช้งานและสิ่งที่ยังต้องตรวจ

ข้อมูลเพียงพอสำหรับเปิดดูโซนเบื้องต้นและเตรียมสำรวจ ไม่ใช่การรับรองจำนวนคันชาร์จต่อวันหรือการคืนทุน ตัวเลขจากลอจิกเดิมของลำปางยังเป็นการคัดกรอง ไม่ใช่ยอดขายที่สอบเทียบกับธุรกิจในเถินแล้ว

ผลทดสอบ API และหน้า Planning ในเครื่อง ปี 2569 / Base / Urban / กริด 1 กม.:

- API สร้าง 242 กริดทั้งจังหวัด โดยมี 29 กริดในกรอบตรวจรอบเถิน 17.60–17.68, 99.20–99.28
- กริดใกล้ปั๊มและจุดคลิกใช้ประเภท highway / AADT 13,337 เหมือนกัน
- ความเข้ม Demand กริดใกล้ปั๊มประมาณ 0.119 เทียบกับค่าสูงสุดทั้งจังหวัด ขณะที่หน้า Planning แสดงสีเฉพาะค่าตั้งแต่ 0.30 จึงไม่เห็นสี Heat ตรงปั๊มในมุมมองนี้ แม้ API มีข้อมูลอยู่ ไม่ได้ลดเกณฑ์เพื่อทำให้พื้นที่ดูร้อนขึ้น
- การไม่ขึ้นสีไม่ใช่ข้อพิสูจน์ว่าไม่มีลูกค้าชาร์จ แต่เป็นผลการคัดกรองเทียบทั้งจังหวัดภายใต้ข้อมูลและลอจิกปัจจุบัน
- ค้นหาชื่อไทยและอังกฤษได้ แผนที่เลื่อนไปจุด Shell ถูกต้อง และโหลดภาพแผนที่พื้นหลังจริงแล้ว
- ทดลองนำเข้าฐานข้อมูล SQLite ในหน่วยความจำได้ โดยเก็บ source URL ของ Shell และกำลังตู้ตามข้อมูลผู้ประสานงาน รวมถึง Spark 240 kW ไม่ได้เขียน production DB
- ชั้นน้ำออนไลน์ยังคืน HTTPError ในการทดสอบจุดคลิก จึงยังไม่ถือว่าตรวจการทับแหล่งน้ำออนไลน์ครบ แม้หน้าแผนที่และ Heat Map API ทำงานได้

1. ตรวจว่าปั๊ม Shell มี EV charger เดิมหรือกำลังก่อสร้างหรือไม่
2. ตรวจฝั่งถนน จุดกลับรถ ระยะขับจริง ทางเข้า รถเข้าพักต่อวัน และระยะจอด โดยแยกจาก AADT
3. ตรวจสถานะเปิดใช้ กำลังต่อหัว จำนวนหัว CCS2 และการแบ่งกำลังในแอป PluZ / EleXA / Spark โดยเฉพาะ EleX PT เถินที่ยังขาดพิกัด
4. ตรวจสิ่งอำนวยความสะดวกที่เปิดจริงในช่วงกลางคืนและกำลังไฟ/หม้อแปลงที่รองรับได้
